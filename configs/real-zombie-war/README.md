# Real Zombie War

OverScreen config for **Real Zombie War** (package `com.soupenoodles.realzombiewar`).

## How to use

1. Download [`config.json`](config.json) to your phone.
2. In OverScreen, import it from the backup screen (backup is part of OverScreen Pro).

The import adds or replaces only the items of this file. The configs of your other apps are left untouched. It also applies the "pause when leaving the app" setting stored in the file.

## Content

- 4 sequence(s), 3 marker(s), list(s): Liste 1
- Auto-watch: not enabled for this app.
- Recorded on a screen of 1080x2400 pixels; on another resolution the positions may need adjusting.

### Sequences

- Move Left / Right
- Move Left / Right (copie)
- Play
- Retry

### Markers

- Repère 1
- Repère 2
- Repère 3
